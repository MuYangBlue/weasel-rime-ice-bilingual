# 小狼毫输入法本地定制

基于 **小狼毫（Weasel）0.17.4 + 雾凇拼音（rime-ice）** 的个人配置与定制，
主要特色是**候选窗双语显示**：输入中文时，在候选右侧显示对应英文释义，顺便记单词。

```
1. 说    to speak  v.
         to talk   v.
         to say    v.
2. 苹果  apple
```

## 功能

- **候选窗显示英文释义**：中文候选右侧附英文，单字与词组都支持（40,794 条词条）
- **竖排多行**：多个义项逐行显示在候选右侧
- **可上屏英文**：`Ctrl+Shift+Return` 把当前中文换成对应英文单词
- **可开关**：`Ctrl+Shift+T` 临时关闭双语显示（方案选单中显示为「中 / 中英」）
- **词性标注**：释义后附 `v.` / `n.` / `pron.` 等标签（规则推断，见下）

### 输入方案与快捷键

方案表含「雾凇全拼」与「小鹤双拼」两个方案，需要重新部署才生效。

- `Ctrl+1` / `Ctrl+2` 切换方案，**仅在输入法正在拼字（有编码未上屏）时生效**；
- 未拼字时用 `F4` 或 `Ctrl+`` 打开方案选单切换。

这两个键**不能**设为 `when: always`：那样输入法会吞掉所有程序里的 `Ctrl+1`/`Ctrl+2`（浏览器切标签、不少游戏与编辑器都用这两个组合），并顺手切换方案，表现为「方案固定不住、用着用着变回全拼」。

## 安装

1. 安装小狼毫 0.17.4 或更高版本
2. 获取雾凇拼音的完整配置（本仓库不含约 45 MB 的 `cn_dicts/` 词库）：

   ```bash
   git clone https://github.com/iDvel/rime-ice
   cp -r rime-ice/cn_dicts Rime/
   ```

3. 把 `Rime/` 放到小狼毫的用户目录（托盘图标 → 用户文件夹）
4. 重新部署（托盘图标 → 重新部署）

> 注意：修改 `.lua` 文件后**必须重启 WeaselServer 才会生效**。
> 引擎重载（打字、切换方案）不会重新读取 Lua 脚本——模块被 Lua 的
> `package.loaded` 缓存。这是排查问题时容易踩的坑。

## 配置

在 `Rime/rime_ice.custom.yaml` 的 `bilingual_filter` 节调整：

```yaml
bilingual_filter:
  languages: [ en ]   # 语言列表，取第一个命中的
  min_length: 1       # 1 = 单字与词组都显示；2 = 只显示词组
  max_length: 0       # 单行释义长度上限，0 = 不截断
  separator: "  "     # 与已有注释拼接时的分隔符
  format: "{gloss}"   # 显示格式，可用 {gloss} {lang} {word}
  multiline: true     # true = 竖排多行；false = 挤在一行
  pos: auto           # 词性：off / auto / always
```

改完需重新部署，改 `.lua` 还需重启服务。

### 导入外部词库

项目提供 `Rime/tools/import_rime_dict.py`，把外部词表转换成可供全拼和双拼共同使用的 Rime 词典。输入文件使用 UTF-8，每行格式为：

```text
专业名词\tzhuan ye ming ci\t200
```

也可以省略权重：

```text
专业名词\tzhuan ye ming ci
```

执行：

```bash
python Rime/tools/import_rime_dict.py 输入.txt Rime/imported_terms.dict.yaml --name imported_terms
```

`Rime/rime_ice.dict.yaml` 的 `import_tables` 中预留了 `imported_terms` 条目，但默认**注释掉**——生成的词典属于本地个人内容，不纳入本仓库。需要用外部词库时，先运行上面的命令生成词典，再取消该行注释并重新部署即可。词典保存的是全拼编码；小鹤双拼等已有双拼方案会根据自身规则转换输入，因此同一份词典可以同时服务全拼和双拼。脚本不会自动修改其他方案文件，也不会覆盖动态用户词库。

### 用户中心与统一目录

用户中心基础界面位于 `用户中心/main.py`，统一工作目录为：

```text
data/       统计和词频数据
import/     待导入词库
backup/     配置备份
```

当前可用功能包括打开目录、把词库拖入导入区、重新部署、重启算法服务和备份当前配置。启动方式：

- 直接双击 `用户中心/启动用户中心.bat`（优先启动打包后的 EXE）；
- 双击 `用户中心/安装用户中心.bat` 可创建桌面快捷方式并设置开机启动；
- 双击 `用户中心/卸载用户中心.bat` 可移除这两项；
- 或运行源码：

```bash
python 用户中心/main.py
```

当前用户中心只操作本项目工作区，不会自动删除旧配置或覆盖用户词库。

用户中心通过向上查找包含 `Rime` 目录的祖先来定位工作区，因此**源码运行与打包后的 EXE 指向同一个真实工作区**。此前按固定层数推导路径，打包版会误把 `用户中心/dist/小狼毫用户中心` 当成工作区，导致统计读不到、部署按钮无效。

### 输入统计

输入统计由 `Rime/lua/input_stats.lua` 负责，只保存每日汇总数字，不保存输入原文、候选上下文或剪贴板内容。统计写入 `data/input_stats.tsv`（若该文件不存在，则先读用户目录下的 `lua/input_stats.tsv` 作为旧数据来源）。统计字段包括提交次数、总字符数、中文字符数、英文字母数、数字数、标点数、当天第一次与最后一次提交时间、24 个小时的上屏字符数分布，以及**活跃码字时长**。

活跃时长（第 11 列 `active_seconds`）在 3.4.31 起改为**按键级口径**：统计每次按键与上一次按键的间隔，只把前 **3 秒**计入，超出部分视为空档不计。这与阅文作家助手的 `idleDuration < 3` 判定一致。

此前 3.4.30 的口径是「相邻两次上屏间隔不超过 120 秒就整段计入」，会把想事情的百来秒也算成码字，明显虚高。

两种口径的实际差别：

| 场景 | 3.4.30（上屏间隔 120 秒） | 3.4.31（按键间隔 3 秒） |
|---|---|---|
| 打一句，停下来想 100 秒，再打一句 | 100 秒全部计入 | 只计前 3 秒 |
| 连续快速打字 | 正常计入 | 正常计入 |
| 最后一次按键后的静默 | 不计入 | 不计入 |

实现说明：Rime 的 Lua 环境没有定时器，processor 只在按键时被调用，因此无法复刻「每秒 tick、3 秒后自动停表」。改为在下次按键到来时回算上一段，效果等价——最后一次按键后的静默同样不计时。

**语义提醒**：输入法看不到文档内容，这个时长统计的是「全系统键盘活跃时长」。聊天、写代码、填表格同样会被计入，不是纯粹的写作时间。要区分写作与其它输入，只能在写作软件侧取数。

**写盘策略**：按键只在内存里累加时长并把 `dirty` 标记置真，**不触发磁盘写入**；由下一次上屏顺带写出。这样敲键盘时不碰磁盘、不影响输入响应，同时把数据丢失窗口压缩到一个上屏周期（十几秒）。若改成每次上屏都强制写盘（`SAVE_EVERY = 1`，当前即为该值），日码 1 万字约每天写入 66 MB、每年 24 GB，对本机 NVMe SSD 的寿命影响可忽略；而逐键写盘（每年约 200 GB）会拖慢输入，已否决。

该字段是 3.4.30 新增的，3.4.31 起改为按键级 3 秒口径。历史行没有它，读取时按 0 处理并显示为 `00:00:00`，不伪造补值。旧版 9 列、10 列格式都能正常读取。

**历史数据不重算**：改口径前的时长按旧规则如实保留，新旧数据并存时曲线会出现台阶。旧记录没有按键级信息，重算只能凭上屏时间戳估算，等同于编造，因此不做回填。

修改 Lua 后需要重新部署，并重启算法服务使脚本重新加载。

用户中心「输入统计」页提供：今日卡（字数与时长）、7/15/30 天折线趋势与区间平均/最高/累计、码字日历热力、本月日均与月概况（总字数、累计时长、写作天数、最长连续天数），以及按选中日期展示的指标方块区。区间与本月平均都按**有记录的天数**计算。

指标方块区随日历选中日期联动：点某一天，该日的总字符、中文、英文、数字、标点、码字时长、提交次数、活跃区间、高峰时段以九个小方块并排显示（此前是横向铺开的多日大表格）。统计页每 5 秒自动重读一次数据文件，打字时数字会自行更新。

### 关于词性

CC-CEDICT 本身**不含词性字段**，标签是由英文释义的书写习惯**规则推断**的
（如 `to xxx` → 动词）。实测 30.4% 的词条能判定，其余不标注。

这是启发式结果，不是权威标注；不需要可设 `pos: off`。

`pos: auto` 会避免重复：单义项直接显示；多义项若词性相同
（如「我 → I / me / my」都是 `pron.`）则隐藏标签，仅在词性不同时显示。

## 重新生成数据

数据由 `Rime/tools/build_bilingual_dict.py` 生成，重新运行是安全的：

```bash
# 默认：词组 + 单字
python Rime/tools/build_bilingual_dict.py

# 只要词组
python Rime/tools/build_bilingual_dict.py --no-single-char

# 不附加词性标签
python Rime/tools/build_bilingual_dict.py --no-pos
```
